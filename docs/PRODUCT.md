# PRODUCT

## Что такое UiGo

UiGo - мобильный радар для поиска свободных квартир, апартаментов и номеров для почасовой и посуточной аренды.

Пользователь открывает экран "Радар", видит ближайшие объекты и их статус готовности: свободно сейчас, освободится скоро, освободится позже, время уточняется или занято. Главная цель MVP - быстро понять, где можно заселиться сейчас или в ближайшее время, открыть детали объекта и отправить действие "Бронь".

Это не продукт долгосрочной аренды. В интерфейсе и данных не используются помесячные цены.

## Цены

Валюта MVP: тенге, символ `₸`.

У объекта всегда есть две цены:

- `hourlyPrice` - цена за час.
- `dailyPrice` - цена за сутки.

Примеры:

- 7 000 ₸ / час, 22 000 ₸ / сутки.
- 10 000 ₸ / час, 30 000 ₸ / сутки.
- 15 000 ₸ / час, 45 000 ₸ / сутки.

## Роли MVP

В первой версии есть только две роли:

- Арендатор - ищет свободный объект через мобильный радар.
- Владелец - размещает объект и отвечает на заявки.

Админ-панель, admin dashboard, админские маршруты, экраны и кнопки не входят в MVP.

## Экран арендатора: Радар

Экран `app/map/index.tsx` по смыслу называется "Радар".

Основные элементы интерфейса:

- Радар.
- Срочно нужна.
- Фильтр.
- Район или адрес.
- Свободно сейчас.
- Освободится скоро.
- Освободится позже.
- Время уточняется.
- Занято.

В MVP реальная карта не подключается. Для проверки интерфейса используется имитация радара с моковыми метками. 2GIS остается продуктовой целью, но Expo Go-совместимость проверяется отдельно.

## Статусы готовности объекта

- `available_now` - свободно сейчас, цвет green.
- `available_soon` - освободится скоро, цвет yellow.
- `available_later` - освободится позже, цвет orange.
- `unknown_time` - время уточняется, цвет gray.
- `occupied` - занято, цвет red.

## Поля объекта

Минимальная модель объекта для MVP:

- `id`.
- `title`.
- `type`: `apartment`, `room`, `aparthotel`.
- `city`.
- `district`.
- `address`.
- `hourlyPrice`.
- `dailyPrice`.
- `availabilityStatus`.
- `availableInMinutes`.
- `availabilityLabel`.
- `viewsCount`.

## Казахстанские моковые объекты

Моки для MVP должны использовать Казахстан:

- Алматы, Центр.
- Алматы, Самал.
- Алматы, Арбат.
- Астана, Левый берег.
- Шымкент, Центр.

Не использовать польские города и районы.

## Подписи меток радара

- `available_now`: цена за час, например `7 000 ₸/ч`.
- `available_soon`: `через 30 мин`.
- `available_later`: `через 2 ч`.
- `unknown_time`: `уточняется`.
- `occupied`: `занято`.

## Карточка объекта

Карточка объекта на деталях показывает:

- тип объекта;
- город и район;
- цену за час;
- цену за сутки;
- статус готовности;
- время до освобождения, если `availableInMinutes` есть;
- просмотры;
- активность владельца: среднее время ответа и процент ответов;
- кнопку "Бронь";
- кнопку "Радар" для поиска других вариантов.

В MVP push-уведомление владельцу показывается как мок-состояние на экране владельца. Production push notifications не подключаются.
