# USER FLOWS

## Гость смотрит UiGo

1. Гость открывает приложение.
2. Видит витрину свободных объектов.
3. Может открыть `Радар`.
4. Может открыть детали объекта.
5. Не может открыть личное меню или кабинет без demo-регистрации.

Результат: публичная часть доступна без входа, личные действия требуют email.

## Гость открывает меню

1. Гость нажимает нижнюю круглую Home-кнопку UiGo.
2. Меню не открывается.
3. Приложение ведет на `/auth?intent=open_menu`.
4. После ввода email пользователь попадает на `/onboarding`.

Результат: личное меню не доступно неавторизованному пользователю.

## Demo-регистрация

1. Пользователь вводит email на `/auth`.
2. Приложение считает demo-пользователя авторизованным до перезагрузки.
3. Пользователь переходит на `/onboarding`.
4. Выбирает `Найти жилье` или `Сдать жилье`.

Результат: новый пользователь не попадает сразу в готовый кабинет.

## Новый арендатор

1. Пользователь выбирает `Найти жилье`.
2. Открывается `/profile/setup`.
3. Пользователь вводит имя, телефон, город и цель.
4. После анкеты открывается кабинет арендатора.
5. Кабинет показывает только реальные demo-данные пользователя, без старой истории и fake-заявок.

Результат: новый аккаунт выглядит пустым и честным.

## Бронь гостем

1. Гость открывает детали объекта.
2. Нажимает `Бронь`.
3. Приложение ведет на `/auth?intent=booking&propertyId=...`.
4. После email открывается `/onboarding`.
5. Пользователь выбирает `Найти жилье`.
6. Заполняет анкету арендатора.
7. Приложение создает demo-заявку по выбранному объекту и открывает `/requests?created=1&propertyId=...`.

Результат: бронь не теряет выбранный объект и не ведет арендатора в owner demo.

## Бронь авторизованным арендатором

1. Авторизованный арендатор с заполненной анкетой открывает детали объекта.
2. Нажимает `Бронь`.
3. Приложение создает demo-заявку.
4. Открывается экран `Мои заявки`.

Результат: заявка появляется только после реального действия пользователя.

## Меню авторизованного пользователя

1. Авторизованный пользователь нажимает нижнюю круглую Home-кнопку UiGo.
2. Кнопка скрывается.
3. Темная glass-капсула плавно вырастает из кнопки вверх.
4. Пользователь выбирает `Радар`, `Кабинет`, `Мои заявки`, `Для владельца`, `Витрина` или `Выйти`.
5. Тап вне капсулы, крестик или свайп вниз закрывает меню.

Результат: навигация доступна в одном нижнем tactile-контроле и не сдвигает экран.

## Владелец

1. Авторизованный пользователь выбирает `Сдать жилье` на onboarding или `Для владельца` в меню.
2. Открывается легкий owner demo.
3. Владелец видит свои объекты, готовность и входящие demo-заявки.

Результат: это кабинет владельца, не админка.
