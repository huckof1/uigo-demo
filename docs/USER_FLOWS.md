# USER FLOWS

## Арендатор открывает радар

1. Арендатор открывает UiGo.
2. Нажимает "Открыть радар".
3. Видит экран "Радар".
4. Вводит "Район или адрес" или смотрит ближайшие метки.
5. Использует "Фильтр", если нужно сузить выдачу.

Результат: арендатор видит свободные квартиры, апартаменты и номера для почасовой или посуточной аренды.

## Арендатор выбирает объект

1. Арендатор нажимает метку на радаре.
2. Система показывает карточку объекта.
3. Карточка показывает тип, район, `hourlyPrice`, `dailyPrice`, статус готовности и просмотры.
4. Если есть `availableInMinutes`, карточка показывает, через сколько объект освободится.

Результат: арендатор быстро понимает, можно ли заселиться сейчас или скоро.

## Бронь

1. Арендатор открывает детали объекта.
2. Видит активность владельца: среднее время ответа и процент ответов.
3. Нажимает "Бронь".
4. Система создает мок-заявку и переводит на экран владельца.
5. Экран владельца показывает "Push-уведомление отправлено" как демо-состояние.

Результат: арендатор видит, что заявка дошла владельцу, без подключения реального backend.

## Статусы на радаре

- `available_now`: показывать цену за час.
- `available_soon`: показывать "через 30 мин".
- `available_later`: показывать "через 2 ч".
- `unknown_time`: показывать "уточняется".
- `occupied`: показывать "занято".

## Что не входит в текущую задачу

- Реальная карта.
- Supabase.
- Production push notifications.
- Админка.
