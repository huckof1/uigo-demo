# CODEX MEMORY

## Концепция UiGo

UiGo Demo - мобильный радар для поиска свободных квартир, апартаментов и номеров для почасовой и посуточной аренды.

Это не приложение долгосрочной аренды.

## Главные правила

- Использовать русский язык в UI.
- Использовать тенге `₸`.
- Не использовать помесячные цены.
- Не использовать старую англоязычную формулировку про rental в реальном времени.
- В русском UI использовать "Свободно сейчас" для немедленной доступности.
- Не использовать польские города и районы в моках.
- MVP тестируется в Expo Go на iPhone 11.
- Основной стек: Expo, React Native, TypeScript, Expo Router.
- Supabase не подключать без отдельной задачи.
- Реальную карту не подключать без отдельной задачи.
- 2GIS native SDK не использовать в Expo Go; сначала проверять WebView/MapGL как отдельный этап.
- Не добавлять новые библиотеки без явного запроса.
- Не делать админку в MVP.
- В MVP есть две роли: арендатор и владелец.
- На деталях объекта использовать CTA "Бронь" и "Радар", не "Смотреть сейчас" и не "Срочно нужна".
- Production push notifications не подключать; показывать только мок-состояние.

## Радар

Экран `app/map/index.tsx` называется "Радар" и является экраном арендатора.

Обязательные тексты:

- Радар.
- Срочно нужна.
- Фильтр.
- Район или адрес.
- Свободно сейчас.
- Освободится скоро.
- Освободится позже.
- Время уточняется.
- Занято.

## Модель объекта

Объект должен иметь:

- `hourlyPrice`.
- `dailyPrice`.
- `availabilityStatus`.
- `availableInMinutes`.
- `availabilityLabel`.
- `type`: `apartment`, `room`, `aparthotel`.
- `city`.
- `district`.

## Статусы готовности

- `available_now` - green.
- `available_soon` - yellow.
- `available_later` - orange.
- `unknown_time` - gray.
- `occupied` - red.
