# CODEX MEMORY

## Концепция UiGo

UiGo Demo - мобильный радар свободных квартир, апартаментов и номеров для почасовой и посуточной аренды.

Это не приложение долгосрочной аренды на месяц.

## Главные правила

- UI на русском языке.
- Валюта только тенге: `₸`.
- Цены показываются за час и за сутки: `hourlyPrice`, `dailyPrice`.
- Не использовать месячные цены, Warsaw, доллары, `Available now`, тексты про долгосрочную аренду.
- MVP тестируется в Expo Go на iPhone 11.
- Основной стек: Expo, React Native, TypeScript, Expo Router.
- Supabase не подключать без отдельной задачи.
- Реальную карту и 2GIS native SDK не подключать без отдельной задачи.
- Не добавлять новые библиотеки без явного запроса.
- Не делать админку. В MVP только роли арендатора и владельца.
- Production push notifications не подключать; пока только demo-состояния.

## Доступ гостя

- Гость может смотреть витрину, радар и детали объекта.
- Гость не видит личное меню и кабинет.
- Глобальная нижняя Home-кнопка UiGo у гостя ведет на `/auth?intent=open_menu`.
- Кнопка `Бронь` у гостя ведет на `/auth?intent=booking&propertyId=...`.

## Demo-регистрация

- Регистрация локальная, без Supabase.
- Ввод email сразу авторизует пользователя до перезагрузки приложения.
- После email пользователь попадает на `/onboarding`, а не сразу в кабинет.
- На `/onboarding` пользователь выбирает:
  - `Найти жилье` -> `/profile/setup`;
  - `Сдать жилье` -> owner demo.

## Анкета арендатора

- Новый арендатор должен заполнить MVP-анкету:
  - имя;
  - телефон;
  - город;
  - цель: `на несколько часов`, `на сутки`, `срочно сейчас`.
- До заполнения анкеты кабинет не должен выглядеть готовым.
- Нельзя показывать старые mock-заявки или историю как будто они принадлежат новому пользователю.
- Если пользователь пришел из `Бронь`, после анкеты создать demo-заявку по выбранному объекту и открыть `Мои заявки`.

## Меню

- Навигация после витрины и радара: глобальная нижняя Home-кнопка UiGo по центру.
- На `/auth` кнопка скрыта.
- Закрытое состояние: круглая tactile-кнопка около `62x62` с темным liquid glass и светящейся UiGo-точкой.
- Для авторизованного пользователя кнопка плавно раскрывается вверх в компактную нижнюю glass-капсулу.
- Пока капсула открыта, отдельная кнопка скрыта и становится частью открытого меню.
- Экран под меню не сдвигать и не масштабировать.
- Закрытие: тап вне меню, крестик, выбор пункта или свайп вниз.
- Пункты меню: `Радар`, `Кабинет`, `Мои заявки`, `Для владельца`, `Витрина`, `Выйти`.

## Радар

- Экран `app/map/index.tsx` называется `Радар`.
- Это экран арендатора для быстрого поиска заселения.
- Метки показывают цену или время освобождения.
- Выбранная юрта должна визуально выделяться на карте.
- Поиск должен понимать город, район, адрес, тип, цену и отдельные слова.

## Статусы готовности

- `available_now` - зеленый, свободно сейчас.
- `available_soon` - желтый, освободится скоро.
- `available_later` - оранжевый, освободится позже.
- `unknown_time` - серый, время уточняется.
- `occupied` - красный, занято.
