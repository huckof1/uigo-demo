# ROADMAP

## Этап 1: Концепция

- UiGo - мобильный радар почасовой и посуточной аренды.
- Казахстан, русский UI, цены в `₸`.
- Только роли арендатора и владельца.
- Без админки.

## Этап 2: Expo Go каркас

- Expo + React Native + TypeScript.
- Expo Router.
- Safe area для iPhone 11.
- Reanimated, Gesture Handler, BlurView, Haptics.
- Без Next.js как основного стека.

## Этап 3: Витрина и радар

- Главная витрина свободных объектов.
- Радар с mock-картой/2GIS WebView-вариантом без native SDK.
- Казахстанские mock-объекты с `hourlyPrice`, `dailyPrice`, `availabilityStatus`.
- Поиск по городу, району, адресу, типу и цене.

## Этап 4: Детали и бронь

- Детальная страница объекта с фото, ценой, статусом и владельцем.
- CTA `Бронь` и `Радар`.
- Гость при брони идет в demo-регистрацию.
- Арендатор без анкеты сначала заполняет профиль.
- Заявка создается только после действия `Бронь`.

## Этап 5: Demo-session и onboarding

- Локальная demo-session без Supabase.
- Email сразу авторизует пользователя до reload.
- После email показывать `/onboarding`.
- Роль/режим:
  - `Найти жилье` -> анкета арендатора;
  - `Сдать жилье` -> owner demo.
- Новый кабинет арендатора пустой до реальных demo-действий.
- Старые mock-заявки не показывать как историю нового пользователя.

## Этап 6: Глобальное меню

- Глобальная нижняя Home-кнопка UiGo по центру на всех публичных и личных экранах, кроме `/auth`.
- Для гостя кнопка ведет на регистрацию.
- Для авторизованного пользователя круглая кнопка открывает компактную нижнюю glass-капсулу.
- Капсула визуально растет из кнопки вверх, экран под ней не сдвигается.

## Этап 7: Кабинеты

- Кабинет арендатора показывает email, анкету и реальные demo-заявки.
- `Мои заявки` показывает пустое состояние или заявки, созданные через `Бронь`.
- Owner demo показывает объекты владельца, доступность, заявки и активность ответа.
- Owner demo не является админкой.

## Этап 8: Backend later

- Supabase подключать только отдельной задачей.
- Не хранить реальные ключи в репозитории.
- Реальные OTP, email, SMS, push и RLS - после стабилизации UX.

## Этап 9: Premium polish

- Liquid glass через BlurView.
- Живые radar markers.
- Haptics на ключевых действиях.
- Проверка производительности на iPhone 11 в Expo Go.
