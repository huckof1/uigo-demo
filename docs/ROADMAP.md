# ROADMAP

## Этап 1: Концепция и документация

- Зафиксировать UiGo как мобильный радар почасовой и посуточной аренды.
- Убрать логику долгосрочной аренды.
- Зафиксировать валюту `₸`.
- Описать поля `hourlyPrice`, `dailyPrice`, `availabilityStatus`, `availableInMinutes`, `availabilityLabel`.
- Описать статусы готовности объекта.
- Зафиксировать Казахстан как базовый регион моков MVP.

Результат: проект не смешивает долгосрочную и краткосрочную аренду.

## Этап 2: Expo Go каркас

- Expo + React Native + TypeScript.
- Expo Router.
- iPhone 11 safe area.
- Reanimated, Gesture Handler, BlurView, Haptics.
- Без Next.js как основного стека.

Результат: мобильный каркас запускается в Expo Go.

## Этап 3: Проверочный экран арендатора

- Главный экран с CTA "Открыть радар".
- Экран `app/map/index.tsx` с названием "Радар".
- Моковые метки объектов без реальной карты.
- Карточка объекта с ценой за час, ценой за сутки и статусом готовности.

Результат: арендаторский сценарий можно проверить на iPhone 11.

## Этап 4: Радар и карта

- Проверить 2GIS MapGL JS внутри `react-native-webview` в Expo Go.
- Если WebView не подходит, использовать временный Expo Go-compatible fallback.
- Native 2GIS SDK рассматривать только для development build/dev client.
- Не подключать реальную карту до отдельной задачи.

Результат: выбран реалистичный путь карты.

## Этап 5: Объекты

- Реализовать список объектов Казахстана.
- Поддержать типы: квартира, номер, апарт-отель.
- Поддержать статусы готовности.
- Поддержать метки радара:
  - цена за час;
  - через 30 мин;
  - через 2 ч;
  - уточняется;
  - занято.

Результат: радар показывает полезную доступность, а не просто объявления.

## Этап 6: Бронь арендатора

- "Бронь" на деталях объекта.
- "Радар" как возврат к поиску других вариантов.
- Мок-заявка владельцу.
- Мок-состояние push-уведомления.
- Простые статусы заявки.
- Haptic feedback и bottom sheet flow.

Результат: арендатор быстро отправляет бронь по объекту.

## Этап 7: Владелец

- Легкая панель владельца.
- Управление доступностью объекта.
- Ответ на заявки.

Результат: владелец управляет временем готовности объекта.

## Этап 8: Supabase

- Подключить Supabase только после отдельной задачи.
- Подготовить RLS и миграции.
- Не хранить реальные ключи в репозитории.

Результат: backend подключается после стабилизации мобильного UX.

## Этап 9: Premium polish

- Liquid glass через BlurView.
- Animated radar markers.
- Skeleton loading.
- Native-like bottom sheets.
- Haptics на важных действиях.
- Проверка FPS на iPhone 11.

Результат: MVP ощущается как premium mobile demo.
